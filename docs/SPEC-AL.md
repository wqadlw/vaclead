# SPEC-AL · 智能推荐轮：先打给谁（Agent B 认领）

> 立项：2026-11-05 W54 · 数据池 26,817 家/13,389 家可拨——拓客核心问题从
> "找不到客户"变成"**先打给谁**"。头部平台（探迹 AI 推荐/ZoomInfo NBC）的
> 答案：意图+信号+成交概率排序 + 可解释推荐。我们的差异化武器：**可拨电话**
> （探迹不提供）+ 公告级证据。

## 调研吸收

- 探迹 AI 推荐：多维度筛选+自动识别高意向+成交概率预测
- Demandbase/NBC 流派：账号数据 × 购买信号 × 上下文 → 排序 + next-best-action
- 共识：**推荐必须可解释**（为什么推荐它）——本平台全库行为数据可出人话理由

## AL1 推荐引擎（app/recommend.py）

`score_candidates(session, limit) -> [{ent_id,name,city,industry_name,phone,score,reasons}]`

打分模型（可解释加权，Python 侧计算——SQL 预筛 + 内存评分）：

| 维度 | 分值 | 理由文案 |
|---|---|---|
| 有可拨电话（phones_json 非空） | +30 | 有公开电话，可直接触达 |
| 近 30 天有新信号（中标/招标/备案） | +25 | 近期有采购相关动态（引用最新信号类型） |
| 意图分 | ×0.2（≤20） | 意图热度 N 分 |
| 买家行业 tier | tier1 +10 / tier2 +5 | 高优行业（TIER-1） |
| 未占用销售资源（无 following/intent 线索） | +15 | 尚未分配跟进，先到先得 |
| 近 90 天有项目备案（proposal） | +15 | 扩张前兆期 |

排除：is_competitor（同行不推荐）；无电话且无信号的企业不进候选（推荐必须
"打得通或有事由"）。
