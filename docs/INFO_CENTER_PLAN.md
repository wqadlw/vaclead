# 情报中心功能组 · 详细开发文档 v2（推翻 v1 数据管理版）

> v1 设计被否（IT 数据管理门户视角——导入历史/批次台账/溯源查询是数据
> 工程师要的）。**昊志的商业模式：卖真空泵给有真空工艺需求的企业**。
> 信息的唯一价值 = 变成商机。v2 重新定位：**情报中心 = 把分散的信号
> 变成"今天该打谁"的时机判断**。对标：Veloxy 信号优先排序、Crayon/
> Kompyte 竞争情报、探迹商业洞察。

---

## 一、核心洞察：信息的价值 = 时机

销售不缺名单（2.7 万家企业），缺的是**"现在该打谁"**的判断。
一个企业 30 天内同时出现"中标+备案"两个信号 = 正在扩产 = **新泵采购
窗口**。这就是情报中心要自动干的事：

```
分散信号（中标/备案/官网变更/招聘/新号码）
        ↓ 聚合
机会雷达：每家企业的"采购时机分"（多信号加权，30 天窗口）
        ↓ 排序
情报晨报：本周最热 20 家（每家带"为什么是现在"的信号组合解释）
        ↓ 一键
电话名单 → 拨打工作台
```

**数据底座已验证**：真库近 30 天存在多信号企业（research_edu 排除后
有效）。信号类型已齐：tender_win / tender / tender_buy / proposal /
web_change / 新号码入库。

## 三、页面详细规格

### 3.1 情报晨报 `/intel/brief`（🆕 一期核心）

**形态**：按日分组的信息流（像新闻客户端），今天打开=今天的情报。

**情报条目类型与判断规则**（确定性规则，非 AI）：

| 类型 | 触发 | 获客判断（自动生成） |
|---|---|---|
| 🏆 新中标 | tender_win 入库 | "他们刚拿下项目——预算刚花，正是配套设备谈判窗口" |
| 🌱 新备案 | proposal 入库 | "备案=扩产前兆——1-3 个月后有真空泵需求" |
| 🖥 官网变更 | web_change 命中工业词 | "官网提到新产线/招聘——扩张进行时" |
| ☎ 新号码 | 该企业首次出现可拨号码 | "新拿到联系方式——从没打过，优先首访" |
| ⚔ 竞对抢单 | competitor_win | "竞对刚拿下他们的单——替代时机出现" |

**每条情报卡**：类型徽章 + 企业名（链详情）+ 判断语 + 证据句 + 操作组
（拨打/转线索/加入今日名单）。

**头部**：日期切换（看历史）+ 类型筛选 + 「加入今日名单」批量操作
（选中的情报对应联系人 → 直接进 contacts 拨打名单顶部）。

### 3.2 机会雷达 `/intel/opp`（🆕 一期核心）

**采购时机分**（0-100，确定性规则加权）：

```
时机分 = Σ(近 30 天信号 × 类型权重)
  tender_win ×30   （已中标=确定扩产）
  proposal   ×25   （备案=1-3 月窗口）
  web_change ×20   （官网变更命中工业词）
  tender     ×10   （在招=潜在配套）
  新号码      ×15   （首次可拨）
衰减：每条信号按距今天数线性衰减（30 天线性到 0）
```

**页面**：Top 20 热力表（企业/时机分/信号组合徽章/近 30 天信号
时间线小图/操作组）——**"本周最该打的 20 家"**。

**API**：`GET /api/intel/opp?days=30&top=20`（新聚合：signal 按企业
分组 × 类型权重 × 衰减）。

### 3.3 区域市场 `/intel/market`（🆕 二期）

山东主场深耕可视化：16 地市 ×（我们有几家/可拨几家/竞对拿下几家/
备案新 opportunity 几家）——**空白地市**（有真空工艺企业但我们
零覆盖）= 拓客方向。数据：enterprise.geo + 竞对标记 + ggzy 城市字段。
形态：地市表格热力 + 简易地图（复用 /map 的 geoutil）。

### 3.4 情报规则 `/intel/rules`（🆕 二期）

现有 subscription-rules 增强：规则 = (类型/行业/省份/关键词) → 动作
（站内/群播报/进晨报置顶）。把"我关心什么"变成规则，命中自动进晨报
置顶——**情报的个性化订阅**。

## 六、非目标

- 不做通用 BI 看板（导入历史/批次台账等 IT 视角保留在 /data 总览与
  quality，不进情报组）
- 不做爬虫型新数据源（招聘=外链跳转已覆盖，反爬站不碰）
- 不做 AI 生成情报（GLM Key 依赖；确定性规则先行，Key 到位后加
  "情报摘要"段）

## 七、验收

2. 机会雷达：多信号企业排 top（单测锁定时机分计算）
3. 「加入今日名单」→ contacts 拨打名单顶部出现
4. 全量门禁绿
