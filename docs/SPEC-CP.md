## CP1 后端：联系人编辑与删除（intel.py）

- **PATCH /api/contacts/{cid}**（ContactUpdateIn：name/phone/title/role
  全 Optional）：电话走 extract_phones 规范化重写 phones_json；基础号
  查重（同企业其他联系人）；role 白名单校验；返回更新后联系人
- **DELETE /api/contacts/{cid}**：硬删（联系人=公开渠道派生数据，可
  重新回填；风险低全员可删）；返回 {ok: true}
- 两者 current_user 鉴权；404（不存在）

## CP2 前端：联系人页签重构（子 Agent 执行）

- **排序**：可拨（有号码）优先 → 决策链 → 公告验证 → 意图分
- **卡片重设计**：左侧姓名+角色标+职务；中部号码 chips（复制/tel:）；
  右侧快标+编辑/删除（hover 显现，降低视觉噪音）
- **编辑 Modal**：复用"记一条"表单字段，预填现值
- **删除确认**：Modal.confirm 提示"号码将从可拨库移除"
- 拨打引导：卡片顶部"拨打建议"（prep 信号一句话，数据来自既有
  /contacts/{cid}/prep？——从 evidence_claim 取，不新增请求）

## 为谁服务的锚（写进实现注释）

销售一天 N 次：打开情报页 → 看谁 → 拨打 → 记结果 → 修正错误。
联系人面板是 N 次循环的操作面板，不是信息展示页。

## 边界

- 不做联系人恢复（可重新采集/回填）；不挂审计（派生数据低风险）
- 编辑不迁 decision_role/verify_state（采集态字段，手工不改）
