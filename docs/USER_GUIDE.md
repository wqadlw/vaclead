# vaclead 销售使用手册（昊志机械 · 昊青气体装备官方销售商）

> 本手册按销售的真实每日流组织：**早上看什么 → 打电话 → 记结果 → 转线索
> → 报价 → 合同回款 → 老客户维护**。每个环节只讲"在哪点、看什么、下一步"。

## 一、每天早上 10 分钟

### 1. 打开工作台（首页）
- **今日推荐·先打给谁**：系统按"有电话 × 有采购动态 × 行业适配 × 没人跟进"
  排序的每日名单。每条带电话芯片（点击复制）和推荐理由。
- **打电话**：复制号码 → 沟通 → 回到推荐卡点快标：
  「接通」「未接」「空号」——标记后系统自动调整后续推荐。
- **接通且有意向** → 点「转线索」：自动进商机管线并生成 48 小时内首联待办。

### 2. 今日作战 + 我的待办
- 逾期待办（红）/ 今日到期 / 久未跟进 / 高分新线索——四源合并的行动清单。
- OEM 客户每季度有「关系维护」待办（系统每周一自动检查）。

### 3. 流失预警 KPI 卡
- 健康分 <40 的客户数——点进商机管线「流失预警」tab 逐个挽回。

## 二、找客户（三种方式）

### 方式 A：标讯中心（导航第 2 项）
- 全国招标/中标/政采公告流，按行业/省份/关键词筛选。
- 「🌱 拟建·备案」= 扩产前兆（比招标早 1-3 个月）；「🎯 竞对中标动态」=
  竞品的客户动向。每条带**原文链接**可溯源。
- 看中的企业 → 「转线索」或进情报页深查。

### 方式 B：客户地图（导航「客户地图」）
- 全国 10 城打点：**青蓝圆点 = 有公开电话打得通的企业**。
- 缩放到城市看全量；筛选行业/只看有电话；点击看联系卡直达详情。

### 方式 C：企业筛选（导航「企业筛选」）
- 12 维筛选 + Quick picks 快捷片：「有联系电话」「OEM 设备商」「未触达
  （有电话）」「近期有采购」「高意图」…
- 找到后进情报页：工商信息 / 采购关系图谱 / 联系人（带证据）/ 信号时间线。

## 三、打完电话之后

1. **标记结果**：情报页「关键联系人」→ 号码旁 ☎ 下拉选结果
   （接通/有意向/无人接/空号…）——结果会自动反馈给推荐引擎。
2. **记跟进**：线索「记录」侧板写跟进内容 + 下一步动作和时间。
3. **有意向的客户**：商机推进（跟进中 → 意向）→ 填金额/赢率/预计成交月。

## 四、报价与合同

- **报价**：报价单页新建（选产品目录行项目）→ 打印视图发客户。
- **赢单后**：建合同（金额/分期/起止）→ 系统自动跟踪：
  - **回款分期到期** → 逾期自动标红 + 待办提醒负责人
  - **合同到期前 30 天** → 自动续约提醒
- 工作台预测卡可见：在手合同余款 / ⚠ 回款逾期 / 30 天内到期。

## 五、老客户维护（利润大头）

- **装机设备**：每台卖出的泵在情报页「装机设备」tab 登记（型号/序列号/
  安装日期）——系统按耗材时钟（密封 12-24 月/滤芯 2000-4000h）自动生成
  更换回访待办。
- **节能账提案**：情报页「生成节能账」→ 输入客户现有泵参数 → 年省电费/
  5 年累计/回收期 → 一键打印客户提案（含选型推荐+同行公开案例）。
- **替换时机**：泵寿命内性能衰减 + 备件到期 = 换泵谈判窗口，系统按装机
  时钟提醒。

## 六、数据从哪来（合规说明）

- 招标/中标/政采公告：**官方公示平台法定公开内容**，每条带原文链接。
- 项目备案：各省投资项目在线审批监管平台公开备案。
- 联系人电话：公告法定公开联系方式 + 高德地图商家自主公开电话。
- 每日自动采集更新（凌晨批处理），无需人工干预。

## 七、手机上用（外勤模式）

手机浏览器打开同一地址即可，布局自动切换：

- **底部导航**：今日 / 联系人 / 地图 / 线索 / 更多——五个大按钮，拇指直达。
  更多功能（标讯、企业、报表…）在「更多」里按分组找。
- **打电话**：联系人页点号码旁 ☎ 图标直接呼出；号码本身点击复制。
  打完当场标结果（接通/未接/空号），不用回电脑补录。
- **找客户**：地图页城市/行业筛选一行横滑；标讯页筛选同样横滑，
  和高德/企查查一个手势习惯。
- **企业情报页**：头部公司名+操作按钮手机上自动上下排布，
  联系人、图谱、装机各页签照常可用。
- **顶部工具**：左上 ☰ 开导航抽屉，🔍 全局搜索（和电脑 Ctrl+K 同源）。

## 八、工商补数（风鸟搬运）

工商细节（统一社会信用代码/股东/注册资本变更…）平台没有的，去风鸟
（riskbird.com）查，两条路拿回来：

1. **一键直达**：情报页「档案」页签底部 →「一键打开风鸟」→
   自动定位到该企业详情页 → 复制你需要的字段 → 回平台点「粘贴工商信息」
   → 原样粘进框（字段名+值 每行一条）→ 解析入库。
2. **搬运书签**（推荐，一次性安装）：情报页点「搬运书签」按提示把
   「风鸟搬运 → vaclead」拖到浏览器书签栏。之后在风鸟企业页点一下书签，
   数据自动抓取并跳回平台对应企业完成入库——不支持的企业会提示先采集。
   手机 Edge 同样可用（装一次书签栏）。

> 合规边界不变：风鸟仅人工查询 + 官方导出数据入库，不做自动抓取。

## 九、常见问题

| 问题 | 答案 |
|---|---|
| 推荐为什么是这几家？ | 每条带理由（有电话/近期信号/行业适配/未跟进），点企业名看完整档案 |
| 电话打不通怎么办？ | 标「空号」后系统自动排除；「未接」换时段再试（行动建议会给时段提示） |
| 怎么批量导入客户？ | 企业筛选页「批量导入」支持 Excel 粘贴；装机用情报页装机 tab 或粘贴导入 |
| 怎么导出名单？ | 企业筛选页导出按钮（CSV，含联系人列） |
| 忘了某个功能在哪？ | Ctrl+K 命令面板全局搜索；? 键看快捷键 |
