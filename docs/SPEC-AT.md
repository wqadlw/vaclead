# SPEC-AT · 方案武器库轮：节能账 + 客户提案（Agent B 认领）

> 立项：2026-11-06 W57 · Playbook"方案武器库"层（现状 10%）的落地：
> 工程师买"不背锅"（选型计算书）、老板买"节能账"（电费差额×年）。
> 纯计算+模板生成，零新依赖。调研：负载波动场景永磁变频实测节能 30%
> （75KW 含工业电费案例），改造案例 8.7%-30% 按负载率浮动。

## AT1 节能账计算引擎（app/proposal.py）

`roi_calc(power_kw, hours_per_day, load_factor, price_per_kwh, saving_pct)`：
- 基线年电费 = kW × h × 负载率 × 365 × 电价
- 预计年省 = 基线 × 节省率（默认 25%，可调 10-30%——诚实区间）
- 5 年累计 + 回收期（需设备价，来自 product.price 可选）
- 全部字段带公式说明（销售面对工程师质询时每个数字可解释）

## AT2 端点

- `POST /api/proposal/roi` {power_kw, hours_per_day, load_factor,
  price_per_kwh, saving_pct, eid?} → 计算结果
- `GET /api/proposal/print?eid=&power_kw=...`：客户提案 HTML（打印友好，
  复用报价打印视图模式）——含节能账 + 推荐泵型（product_match）+ 昊青
  产品线参数 + 服务承诺栏（区域响应=确定性）

## AT3 前端

- 情报页头部「生成节能账」按钮（所有人可见）→ 参数 Modal（当前功率/
  运行小时/负载率/电价/节省率滑条）→ 结果卡（年省/5 年省/回收期大字）
  + 「打印提案」跳转打印视图

## 边界

- 节省率为可调假设而非承诺（页面标注"按实测案例区间估算"）——销售
  诚实话术，避免过度承诺
- 不做 PDF 文件生成（打印视图=浏览器另存 PDF，零依赖）
