# SPEC-G · 打造标杆：从"功能齐"到"销售离不开"

> 立项：2026-10-26 · 用户授权自主选向
> 我对这个项目的理解：**用户要的不是功能清单，是一个销售打开就不想关的工具**——
> 数据真实可打、每一步都省时间、越来越懂他的生意。当前距离这个标准差的
> 不是广度（28 轮已铺完），是**三根主线还没串成闭环**。

### G5 今日作战清单（60 分钟）
