## 四、数据面动作（随本画像落地）

1. `vertical.py`：NON_CUSTOMER_SOURCES 政采买家源集 + is_non_buyer 加
   source 判定（向后兼容）
2. `contacts.py` _non_buyer_conds()：加 source 条件（三处调用点自动生效）
3. `imports.py` 补数清单：排除政采买家
4. `intel.py` 机会雷达：同语义排除
5. 词表缺口：**医药制造（药厂）**独立类目——待用户确认昊志在制药行业的
   优先级后补词
